Model & fixed priors

A finite 1D target occupies [c − L/2, c + L/2]. Each return has its own unknown source uᵢ, uniform over [−L/2, L/2], plus independent Gaussian noise: zᵢ = c + uᵢ + vᵢ.

Fixed priors: c ∼ N(0, 1.2²) m; L is lognormal with median 4 m and log standard deviation 0.5. Sensor standard deviation is 0.3 m.

The chosen observations are at 25% and 85% of the right half: z₁ = 0.125 L*, z₂ = 0.425 L*. Changing true extent changes this measurement set. These are illustrative observations, not random playback. In real data, individual returns vary.

The estimator receives only the two observations, noise level, and fixed priors. It does not receive true extent, true center, source fractions, or the known side. Both center and size are inferred together from p(c,L | z₁,z₂) ∝ p(c)p(L)ℓ₁(c,L)ℓ₂(c,L).

The orange center likelihood integrates out extent using its prior; the orange extent likelihood integrates out center using its prior. For comparing curve shapes, each orange curve is normalized to unit area over the displayed interval. The posterior is normalized over its full numerical domain. The axes stay fixed as the slider moves.

All updates start from the same prior. Dragging the slider does not accumulate detections. Two returns leave considerable uncertainty about the full body.

Spatial-source convolution: Granström, Baum & Reuter, Eq. (6), specialized to a segment. One target, one scan, two associated returns.
