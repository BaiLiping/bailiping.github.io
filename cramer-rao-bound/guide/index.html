02 · The theorem

The scalar Cramér–Rao Bound.

A floor for the variance of locally unbiased estimators in a regular model.

The bound

Variance has squared parameter units.
Standard deviation has parameter units.

Read the fine print

The theorem has a scope.

Unbiasedness: Eθ[T] = θ in a neighborhood.

Regularity: differentiate under the expectation; the score has mean zero.

Finite information: 0 < Iₙ(θ) < ∞; T has finite variance.

Known model: the likelihood describes the actual experiment.

04 · Attainability

“Lower bound” does not mean “always achievable.”

Equality requires a very specific relationship between the estimator and the score.

Equality in Cauchy–Schwarz

All estimation error aligns with the score.

For uniform attainment, this must define the same statistic T(X) throughout the parameter range.

Three distinct claims

Do not collapse them into one.

Unbiased: expectation equals the target.

Efficient: variance attains the CRB.

MLE: maximizes the likelihood; it may be biased at finite n.

Regular MLEs often approach the bound asymptotically. Finite-sample equality needs its own check.

06 · What else is unknown?

An unknown clock offset consumes position information.

The same measurements must now explain both the target position and a common range offset β.

Partition the information

The position block of J⁻¹ is Jₑ⁻¹, not A⁻¹. Assume the required blocks are invertible.

Interpret the subtraction

Some parameter effects can imitate each other.

If moving the target changes all ranges similarly, an unknown offset can explain part of that same change.

The Schur complement removes information that cannot distinguish position from the nuisance parameter.

No loss when the coupling b is zero. A large loss is possible for clustered lines of sight.

07 · Interpretation

Read a CRB result like a careful reviewer.

Before comparing an algorithm with a bound, make sure they solve the same statistical problem.

01 · Estimator class

Is the comparison valid?

Measure or analyze bias. A learned, constrained, or regularized estimator is not automatically unbiased.

02 · Parameter vector

What was treated as known?

Include unknown offsets, calibration, orientation, or other nuisance parameters before inverting.

03 · Metric and model

Are the units and assumptions aligned?

Match variance with variance, MSE with MSE, and RMSE with a square-root bound. Model correlations correctly.

04 · Local versus global

What can the bound miss?

Inspect rank, conditioning, competing solutions, and low-information regimes. A small local CRB is not a guarantee of successful localization.

08 · Takeaways

Three ideas to keep.

More information lowers the bound. Bias changes the comparison. Geometry decides the weak directions.

01 · Sensitivity

Information belongs to the experiment.

The same estimator can face very different limits under different noise or measurement designs.

02 · Precision

Unbiased variance has a floor.

A better algorithm cannot beat this floor while remaining in the theorem’s estimator class.

03 · Direction

The matrix tells you where.

Independent, complementary measurements are often more valuable than repeated views of the same direction.
