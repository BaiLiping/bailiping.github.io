# Engine lab: Porsche 911 Turbo 3.3 (930), Type 930/60

An interactive model of the air-cooled, turbocharged flat-six. The page is the canvas: grab a part and pull it,
drag the empty stage to turn the engine, hold the throttle and watch boost arrive late.

Unofficial. Built from published dimensions and photographs studied as reference; not affiliated with Porsche.

## Files

| File | What |
|---|---|
| `index.html`, `style.css` | the page: one canvas, two lines of small type |
| `app.js` | input, posing, the frame loop |
| `stage.js` | the Three.js scene: lighting, the ink-line and haze pass, cutaway, picking |
| `sim.js` | a small engine model: throttle → revs → turbo speed → boost, wastegate at 0.8 bar |
| `flow.js` | gas-flow particles along the paths exported with the model |
| `sound.js` | synthesised engine and turbo sound (Web Audio, off until asked) |
| `engine930.glb`, `engine930.json` | the model and its viewer data, generated by `model/build.py` |
| `model/` | the Blender build script, its dimensions (`PARTS.md`) and its limits (`NOTES.md`) |
| `vendor/` | Three.js r187, only the parts used, bundled into one self-hosted file (MIT, licence beside it) |
| `how-it-works/` | the earlier illustrated explainer (jet engine and turbocharged car cutaways), opened from the page with `i` |

## Keys

`↑` throttle · `x` explode · `c` cutaway (top, side, cross-section, off) · `g` gas flow ·
`e` exhaust energy (the exhaust and turbocharger alone, with name tags) · `r` reassemble ·
`space` stop or start the crank · `←` `→` turn it by hand while stopped (shift for one degree) · `m` sound ·
`h` hide the type · `i` how it works · `+` `−` zoom · `0` reset the view. The named commands are also buttons in
the hint line; zoom, reset and turning the crank by hand are keys only (wheel and pinch also zoom).

The page opens with every part out in the exploded view and assembles the engine, the nearest parts first; any
key or click cuts that short. A prompt says that parts can be dragged off; it goes once one has been.

The crank is drawn at one fortieth of its real speed. Sound follows the real revs.

## Rebuild

```
# the model (Blender 5.2 on PATH)
blender -b --factory-startup --python engine-lab/model/build.py

# the Three.js bundle, only when vendor/three-entry.js changes
mkdir /tmp/three && cd /tmp/three && npm init -y && npm install three@0.187.0 esbuild
cp <repo>/engine-lab/vendor/three-entry.js . && npx esbuild three-entry.js --bundle --minify --format=esm \
  --target=es2020 --legal-comments=none --outfile=<repo>/engine-lab/vendor/three.bundle.min.js
```

## Check

```
python3 -m http.server 8765        # from the repository root, then open http://localhost:8765/engine-lab/
python3 scripts/build-search-index.py --check
```

The page makes no third-party requests. It needs WebGL 2. With `prefers-reduced-motion` the crank starts stopped and the opening assembly is skipped.
`window.engineLab.tick(ms)` steps one frame by hand, for checks in a browser window that is not being painted.
At start-up it times a few frames and lowers the drawing resolution and shading quality if the graphics chip
needs it.
